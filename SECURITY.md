# Security Policy

## Supported versions

Only the [latest release](https://github.com/leorac/pwnbrave/releases/latest)
receives security fixes.

## Reporting a vulnerability

Please don't open a public issue for security problems. Report them privately
through GitHub instead:
[Report a vulnerability](https://github.com/leorac/pwnbrave/security/advisories/new).

It helps if you include:

- what the issue is and what an attacker could do with it;
- steps to reproduce, or a proof of concept;
- your Brave version and the PwnBrave version.

This is a personal project maintained in my spare time, so fixes are best
effort, but I'll acknowledge every report and keep you posted until it's resolved.

## Scope

In scope: the extension's own code, for example a page being able to read or
alter PwnBrave's state, change the proxy settings, or spoof a container's color.

Out of scope: issues in Brave, in Chromium, in Burp Suite or in the PwnFox Burp
extension. Please report those to their maintainers.
